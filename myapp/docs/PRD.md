# TaskFlow 产品需求说明书（PRD）

## 1. 项目概述

**产品名称：** TaskFlow — 命令行任务管理工具

**产品定位：** 一个基于命令行的轻量级任务管理工具，面向开发者和技术爱好者，在终端中高效管理日常任务。

**核心价值：**
- 无需离开终端即可管理任务
- 数据本地存储，隐私安全
- 简洁直观的命令交互

## 2. 目标用户

- Rust 学习者（项目所有者）
- 习惯命令行工作流的开发者
- 需要轻量级任务管理工具的技术人员

## 3. 功能需求

### 3.1 核心功能（P0）

#### F1：任务创建
- **描述：** 用户可通过命令创建新任务
- **输入参数：**
  - `title`（必填）：任务标题，1~100 字符
  - `--description / -d`（可选）：任务描述
  - `--priority / -p`（可选）：优先级，可选值 `low | medium | high`，默认 `medium`
  - `--tag / -t`（可选）：标签，逗号分隔，支持多个
  - `--due`（可选）：截止日期，格式 `YYYY-MM-DD`
- **输出：** 创建成功后显示任务 ID 和确认信息
- **验收标准：**
  - 标题为空时提示错误
  - 标题超过 100 字符时提示错误
  - 日期格式错误时提示错误

#### F2：任务列表
- **描述：** 以表格形式展示任务
- **命令：** `taskflow list`
- **筛选参数：**
  - `--status / -s`：按状态筛选 `todo | in_progress | done`
  - `--priority / -p`：按优先级筛选
  - `--tag / -t`：按标签筛选
- **表格列：** ID | 标题 | 状态 | 优先级 | 标签 | 截止日期
- **验收标准：**
  - 无任务时显示友好提示
  - 表格对齐美观
  - 状态和优先级带颜色区分

#### F3：任务更新
- **描述：** 修改已有任务的属性
- **命令：** `taskflow update <id>`
- **可修改字段：**
  - `--title`：新标题
  - `--status`：新状态
  - `--priority`：新优先级
  - `--description`：新描述
  - `--tag`：新标签（覆盖）
  - `--due`：新截止日期
- **验收标准：**
  - ID 不存在时提示错误
  - 更新后显示更新成功信息
  - `updated_at` 字段自动更新

#### F4：任务删除
- **描述：** 删除指定任务
- **命令：** `taskflow delete <id>`
- **行为：**
  - 默认显示确认提示：`确认删除任务 "xxx"？(y/n)`
  - 支持 `--force / -f` 跳过确认
- **验收标准：**
  - ID 不存在时提示错误
  - 确认后删除并显示成功信息
  - 数据文件中对应记录被移除

### 3.2 增强功能（P1）

#### F5：任务搜索
- **描述：** 按关键字搜索任务标题和描述
- **命令：** `taskflow search <keyword>`
- **行为：** 模糊匹配，标题或描述中包含关键字即命中
- **输出：** 以表格展示匹配结果，高亮匹配关键字（可选）

#### F6：任务统计
- **描述：** 展示任务统计信息
- **命令：** `taskflow stats`
- **统计项：**
  - 总任务数
  - 各状态任务数量及占比（todo / in_progress / done）
  - 各优先级任务数量
  - 已完成率（done / total）
  - 已逾期任务数（due_date < 今天 且 status != done）

#### F7：彩色输出
- **描述：** 终端输出带颜色和样式
- **规则：**
  - 优先级 High → 红色，Medium → 黄色，Low → 绿色
  - 状态 Done → 绿色删除线，In Progress → 蓝色，Todo → 灰色
  - 成功信息 → 绿色，错误信息 → 红色，警告 → 黄色

### 3.3 扩展功能（P2）

#### F8：数据导出
- **描述：** 将任务数据导出为 CSV
- **命令：** `taskflow export --format csv -o <filename>`
- **行为：** 导出当前所有任务到指定文件
- **验收标准：** 生成的 CSV 可被 Excel 正常打开

#### F9：删除确认提示
- **描述：** 删除操作前进行确认
- **行为：** 交互式提示，用户输入 y 确认，n 取消

## 4. 数据模型

```
Task {
    id: String          // UUID v4，自动生成
    title: String       // 必填，1~100 字符
    description: Option<String>  // 可选
    status: Status      // Todo | InProgress | Done
    priority: Priority  // Low | Medium | High
    tags: Vec<String>   // 可选，多个标签
    due_date: Option<NaiveDate>  // 可选
    created_at: DateTime<Utc>    // 创建时间
    updated_at: DateTime<Utc>    // 更新时间
}
```

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 存储 | 本地 JSON 文件，路径 `~/.taskflow/data.json` |
| 性能 | 1000 条任务以内，命令响应 < 100ms |
| 错误处理 | 所有错误有友好提示，不 panic |
| 跨平台 | 支持 Windows / macOS / Linux |
| 数据备份 | 每次写入前自动备份为 `data.json.bak`（可选） |

## 6. 约束与假设

- 不考虑多用户并发场景
- 不考虑任务同步功能
- 数据量上限 1000 条
- 终端最小支持 80 列宽度
