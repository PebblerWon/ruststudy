# Rust 进阶教程：补全 TaskFlow 之外的知识

> 你已经通过 `myapp`（TaskFlow）和 `tutorial` 构建了一个完整的命令行任务管理工具。
> 本教程承接其后，专门讲解 **两个项目没有涉及、但日常 Rust 开发必备** 的核心知识。
> 每一章都从"为什么需要"出发，配可运行的示例，最后给出练习与小结。

---

## 0.1 为什么需要这本教程

`myapp` / `tutorial` 已经让你掌握了：

| 已掌握 | 说明 |
|--------|------|
| 模块系统 | `mod` / `use` / 分层架构 |
| 基础数据建模 | `struct` / `enum` / `Option` / `Vec` / `derive` |
| 序列化 | `serde` + `serde_json` |
| 错误处理 | `thiserror`（库层）+ `anyhow`（应用层）+ `?` |
| CLI | `clap` derive |
| 基础 Trait | `Store` 接口抽象、`Display`、`From`、`Default` |
| 基础迭代器 | `filter` / `map` / `collect` |
| 文件 I/O | JSON 读写、备份 |
| 测试 | `#[test]` / `assert_cmd` |

但这些只是 Rust 的"应用层骨架"。Rust 真正区别于其他语言的核心特性——
**所有权、借用、生命周期、智能指针、并发安全、宏**——在 TaskFlow 项目里几乎
没有触碰。本教程就是为你补上这一块。

## 0.3 如何使用本教程

1. **准备一个练习项目**：建议在 `ruststudy/` 下新建一个 `playground` 项目：
   ```bash
   cd /Users/whn/Desktop/ruststudy
   cargo new --name playground playground
   ```
   每章的代码片段都可以粘到 `playground/src/main.rs` 里 `cargo run` 验证。

2. **按顺序读**：第 1-3 章（所有权/借用/生命周期）是 Rust 的地基，必须按顺序。
   后面的章节相对独立，可按需跳读。

3. **动手跑代码**：每段示例都设计为可独立运行。**不要只看**，敲一遍、改一改、
   故意写错看看编译器报什么。

4. **做练习**：每章末尾有 2-4 道练习，难度递增。建议至少完成前两道。

5. **善用编译器**：Rust 编译器（`rustc`）的错误信息是教学级的。遇到红线别慌，
   仔细读它给的提示，经常会直接告诉你怎么改。

## 0.4 约定

- 代码块里 `// ✓` 表示推荐写法，`// ✗` 表示编译失败或有问题的写法。
- `cargo run` 命令默认在 `playground` 项目根目录下执行。
- 涉及到 TaskFlow 项目的对照，会用 `📖 对照` 标注，方便你回想已学知识。
